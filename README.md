# Develop Coaching landing page

A standalone, mobile-first HTML landing page for Develop Coaching.

## Preview locally

```bash
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173`.

## Booking integration

The booking panel in `index.html` is intentionally a visual placeholder. Replace `.calendar-placeholder` with the final scheduling embed when it is approved.

## Content and assets

The page reuses approved copy and media from the existing Develop Coaching schedule-a-call page. The only authored conversion links are “Book a Call”; the footer contains the requested legal links.
